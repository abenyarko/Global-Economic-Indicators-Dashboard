# DAX measures

This folder is reserved for **actual DAX expressions exported from the Power BI model**, with measure names, source tables, units, filter-context assumptions, and the visuals that use them.

## Documentation template

| Measure | DAX expression | Intended filters | Unit | Visual |
|---|---|---|---|---|
| Add an existing measure | Paste its exact formula | Country / region / year as applicable | e.g., USD | Dashboard visual |

Do not treat illustrative formulas as evidence of implemented measures. After export, save the measures in a `.dax` text file and link them from the main README.
